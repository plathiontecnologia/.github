## 🚀 Quem somos

A Plathion desenvolve **gestão empresarial em camadas**: em vez de vender um sistema fechado, organizamos a operação do cliente em pacotes independentes que podem ser combinados conforme a necessidade — do software ao suporte físico do negócio.

## 📦 Nossos pacotes

| Pacote | O que entrega |
|---|---|
| 🖥️ **Sistema** | Software de gestão sob medida para a operação do cliente |
| 📊 **BI** | Painéis e relatórios para decisão orientada a dados |
| 📱 **Mobile** | Aplicativos para operação e atendimento em campo |
| 🌐 **Site** | Presença institucional e comercial na web |
| ☁️ **Infraestrutura** | Servidores, redes e ambientes em produção |
| 💬 **WhatsApp + IA** | Atendimento e automações pela API oficial do WhatsApp, com IA |

> Cada pacote é modular — o cliente monta a combinação que faz sentido para o momento da empresa dele.
